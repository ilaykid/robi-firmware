HeyRobi — אשף התקנה ועיצוב אישי

רובוט AI קולי לילדים בחיבור ישיר ל-Gemini Live • ללא שרת • ללא התקנת תוכנה

🔒 100% מקומי בדפדפן • אפס מידע נשלח לשרת
🛡️
התחייבות לפרטיות מוחלטת — שום מידע לא נשלח אלינו וקל וחומר לא מאוחסן אצלנו!
עמוד זה הוא כלי דפדפן סטטי ומקומי בלבד (Client-Side WebSerial ללא שרת אחורי וללא מסד נתונים). מפתח ה-Gemini שלכם, פרטי ה-WiFi ושמות הילדים לעולם אינם נשלחים למפתחי הפרויקט או לאתר זה, אינם עוברים דרך שום שרת צד-שלישי, ואפילו אינם נשמרים ב-localStorage של הדפדפן שלכם — הם נכתבים ישירות מתוך הדפדפן דרך כבל ה-USB אל שבב הזיכרון הפנימי של רובי אצלכם בבית בלבד.

שלב 1 — חיבור ישיר ל-Google Gemini

הרובוט מתחבר בעצמו דרך ה-WiFi הביתי ישירות ל-Google Gemini Live — בלי שום שרת באמצע! המפתח נשמר אך ורק בזיכרון הפנימי של רובי אצלכם בבית.

איך משיגים מפתח API תוך 30 שניות?
  1. נכנסים אל Google AI Studio — API Keys ומתחברים עם חשבון Google.
  2. לוחצים על Create API key ומעתיקים את המפתח שמתחיל ב-AIza....
  3. מדביקים כאן למטה ולוחצים על בדוק מפתח כדי לוודא שהוא פעיל.
🔒 אפס שליחה ואפס אחסון: המפתח לעולם לא נשלח למפתחי האתר ולא נשמר בדפדפן — הוא נבדק ישירות מול Google ונצרב בכבל ה-USB לתוך רובי אצלכם בבית בלבד.
במסלול החינמי (Free Tier) יש מכסה של כ-45 דקות שיחה נטו ביום (עד 500 סשנים / 1,000,000 טוקנים). ניתן לעקוב אחרי הניצול בזמן אמת בכתובת http://robi.local.

שלב 5 — חיבור ל-WiFi הביתי וצריבה בלחיצה אחת!

חברו את רובי למחשב עם כבל USB-C. בלחיצה אחת הדפדפן יצרוב ישירות לשבב את מערכת HeyRobi ואת ההגדרות שלכם!
🔒 פרטי ה-WiFi שלכם מעובדים בזיכרון ה-RAM של הדפדפן שלכם בלבד — הם אינם נשלחים לאתר זה ואינם נשמרים בשום מקום מחוץ לרובי.

שימו לב: בקר ESP32-S3 מתחבר לרשתות 2.4GHz (אם תשאירו ריק, רובי יפתח נקודת WiFi בשם Robi-XXXX להגדרה מהטלפון).
