שלב 1 — חיבור ישיר ל-Google Gemini

רובי מתחבר בעצמו דרך ה-WiFi הביתי ישירות ל-Google Gemini Live — בלי שום שרת באמצע! המפתח נשמר אך ורק בזיכרון הפנימי של רובי אצלכם בבית.

איך משיגים מפתח API תוך 30 שניות?
  1. נכנסים אל Google AI Studio — API Keys ומתחברים עם חשבון Google.
  2. לוחצים על Create API key ומעתיקים את המפתח שמתחיל ב-AIza....
  3. מדביקים כאן למטה ולוחצים על בדוק מפתח כדי לוודא שהוא פעיל.
פרטיות מלאה: המפתח נבדק ישירות מול Google ולא נשלח לשום שרת צד-שלישי.

שלב 2 — שם הרובוט, שפה ובחירת קול

בחרו איך יקראו לחבר החדש שלכם, באיזו שפה הוא ידבר, ואיזה קול הכי מתאים לו — אפשר לשמוע דגימת קול חיה ממש כאן!

שלב 3 — עיצוב הפנים והתצוגה

בחרו ערכת צבעים לעיני הניאון של רובי! השינוי מוצג מיד בסימולטור המסך העגול משמאל.

שלב 4 — פרופילי ילדים ונושאי שיחה

אפשר להגדיר עד 3 ילדים (או להסיר הכל למצב כללי ללא כפתורים). לכל ילד/ה מופיע כפתור על המסך העגול שנפתח ל-4 פעילויות מותאמות לגיל!

שלב 5 — חיבור ל-WiFi הביתי וצריבה בלחיצה אחת!

חברו את רובי למחשב עם כבל USB-C. בלחיצה אחת הדפדפן יצרוב גם את התוכנה וגם את כל ההגדרות שלכם!

שימו לב: בקר ESP32-S3 מתחבר לרשתות 2.4GHz (אם תשאירו ריק, רובי יפתח נקודת WiFi בשם Robi-XXXX להגדרה מהטלפון).
